## BUG-001 — Многократное `Alt+F3` блокирует мышь

| Поле | Значение |
|---|---|
| **ID** | BUG-001 |
| **Связанный TC** | TC-008 |
| **Severity** | 🔴 Critical |
| **Priority** | High |
| **Окружение** | Windows 10, 2 монитора |
| **Компонент** | Создание скриншота области |

**Шаги воспроизведения:**
1. Запустить приложение.
2. Нажать `Alt+F3`.
3. Не выделяя область, нажать `Alt+F3` ещё 5–6 раз.

**Ожидаемый результат:** повторные нажатия игнорируются, пока активен оверлей выделения.

**Фактический результат:** затемнение накладывается слой за слоем; мышь блокируется, взаимодействие с системой невозможно.

**Влияние:** блокирует работу пользователя в ОС. Требует закрытие приложение через Диспетчер задач.

## BUG-002 — Незавершённый рисунок применяется после смены скриншота

| Поле | Значение |
|---|---|
| **ID** | BUG-002 |
| **Связанные TC** | TC-009, TC-010, TC-011, TC-012 |
| **Severity** | 🟠 Major |
| **Priority** | High |
| **Окружение** | Windows 10 |

**Шаги воспроизведения:**
1. Создать скриншот.
2. Выбрать инструмент «Кисть», зажать ЛКМ в точке A.
3. Провести мышь в точку B, не отпуская ЛКМ.
4. Не отпуская ЛКМ, нажать `Alt+F2`.
5. Отпустить ЛКМ.

**Ожидаемый результат:** после создания нового скриншота старый рисунок сбрасывается; отпускание ЛКМ ничего не рисует.

**Фактический результат:** новый скриншот создаётся, но при отпускании ЛКМ на нём отображается старый рисунок.

**Влияние:** потеря данных, невозможность корректно прервать рисование.

## BUG-003 — Ctrl+C перехватывается глобально

| Поле | Значение |
|---|---|
| **ID** | BUG-003 |
| **Связанный TC** | TC-018 |
| **Severity** | 🟠 Major |
| **Priority** | High |
| **Окружение** | Windows 10 |

**Шаги воспроизведения:**
1. Запустить приложение (создан скриншот).
2. Свернуть или переключиться в Excel.
3. Скопировать любую ячейку через `Ctrl+C`.

**Ожидаемый результат:** `Ctrl+C` работает в контексте активного приложения (Excel).

**Фактический результат:** в буфер обмена попадает скриншот из ScreenshotApp, Excel не копирует.

**Влияние:** глобальный перехватчик ломает работу других программ.

## BUG-004 — Прямоугольник рисуется только в одном направлении

| Поле | Значение |
|---|---|
| **ID** | BUG-004 |
| **Связанный TC** | TC-028 |
| **Severity** | 🟠 Major |
| **Priority** | Medium |
| **Окружение** | Windows 10 |

**Шаги воспроизведения:**
1. Создать скриншот, выбрать «Прямоугольник».
2. Нарисовать прямоугольник из нижнего-правого угла в верхний-левый.
3. Нарисовать прямоугольник из верхнего-правого в нижний-левый.
4. Нарисовать прямоугольник сверху-слева → снизу-справа.

**Ожидаемый результат:** прямоугольник рисуется независимо от направления.

**Фактический результат:** корректно фиксируется только при рисовании сверху-слева → снизу-справа. В остальных случаях — исчезает при следующем рисунке.

**Влияние:** непредсказуемое поведение, потеря рисунка.

## BUG-006 — Индикатор «Прозрачность» работает наоборот

| Поле | Значение |
|---|---|
| **ID** | BUG-006 |
| **Связанный TC** | TC-034 |
| **Severity** | 🟡 Minor |
| **Priority** | Medium |
| **Окружение** | Windows 10 |

**Шаги воспроизведения:**
1. Запустить приложение.
2. Нажимать «−» до 20%.
3. Нажимать «+» до 100%.

**Ожидаемый результат:** 20% — окно прозрачнее; 100% — полностью непрозрачно. Название «Прозрачность» соответствует поведению.

**Фактический результат:** 20% — окно более прозрачное, 100% — полностью непрозрачное. Но логика инвертирована относительно общепринятой нотации — при значении 100% правильнее называть параметр «Непрозрачность».

**Влияние:** вводит пользователя в заблуждение.

## BUG-009 — UI ломается при изменении размера окна

| Поле | Значение |
|---|---|
| **ID** | BUG-009 |
| **Связанный TC** | TC-046 |
| **Severity** | 🟠 Major |
| **Priority** | High |
| **Окружение** | Windows 10 |

**Шаги воспроизведения:**
1. Запустить приложение.
2. Создать скриншот.
3. Развернуть на весь экран или сжать окно.

**Ожидаемый результат:** все элементы адаптируются; кнопки и текст видны.

**Фактический результат:**
- Надпись «Скриншот появится здесь / Колесико мыши — зум» теряет центрирование.
- По умолчанию окно недостаточно велико — кнопка «Отменить (Ctrl+Z)» не помещается.

**Влияние:** часть функционала скрыта от пользователя без ручного ресайза.
