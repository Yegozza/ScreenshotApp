# ScreenshotApp


Ручное тестирование десктопного приложения **ScreenshotApp** — утилиты для создания
скриншотов с возможностью аннотации (рисование, зум, копирование в буфер обмена,
работа из системного трея).

> 📌 Проект выполнен в учебных целях для практики тест-дизайна
